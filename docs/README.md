This folder is the project handover pack for the current repository snapshot.

- [`PROJECT_STATUS.md`](PROJECT_STATUS.md) — evidence-based status and release blockers.
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — current modules, target architecture, and task flow diagrams.
- [`ROADMAP.md`](ROADMAP.md) — staged implementation milestones and exit gates.
- [`SECURITY.md`](SECURITY.md) — threat model and production checklist.
- [`DEPLOYMENT.md`](DEPLOYMENT.md) — local, staging, testnet, and promotion guidance.
- [`ENVIRONMENT.md`](ENVIRONMENT.md) — environment variable groups and secret-handling rules.
- [`WHITEPAPER.md`](WHITEPAPER.md) — technical concept paper and system principles.
- [`SWARM_DESIGN.md`](SWARM_DESIGN.md) — multi-agent roles, boundaries, and rollout plan.

All Mermaid diagrams are source text and render on GitHub. This pack describes the current codebase and the planned future architecture; it does not claim planned features are already implemented. Review the repository's code, tests, and deployed artifacts before relying on any capability.
